# Photorg Setup

## Prerequisites

1. Install Node.js (LTS) and npm.
2. Install Rust toolchain (`rustup`): https://www.rust-lang.org/tools/install
3. Install Tauri platform prerequisites: https://tauri.app/start/prerequisites/

## Install and Run

```bash
npm install
npm run tauri dev
```

## Build

```bash
npm run tauri build
```
